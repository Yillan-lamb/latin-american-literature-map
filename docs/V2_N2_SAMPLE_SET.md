## 5. 地图节点与交互路径

### 国家层

- `V2-GEO-BR`：巴西，技术父级，仅用于里约热内卢归属和国家页原型，不单独作为 V1 研究实体。
- `V1-ENT-0051`：墨西哥，连接恰帕斯、科米坦、圣加布里埃尔和科马拉。
- `V1-ENT-0095`：哥伦比亚，连接阿卡塔卡和马孔多。

### 现实地点页

- 里约热内卢：显示 `《星辰时刻》` 的故事空间关系，展示城市概览坐标及来源。
- 恰帕斯：显示 `《巴伦坎南》` 和卡斯特利亚诺斯的关系，使用区域代表点并标明精度。
- 科米坦：显示卡斯特利亚诺斯的作者地理关系。
- 阿卡塔卡：显示马尔克斯的作者地理关系，点位只代表现实城镇。

### 虚构空间页

- 科马拉：显示 `《佩德罗·巴拉莫》` 的 `fictional_setting`，不使用现实科马拉镇坐标。
- 马孔多：显示 `《百年孤独》` 与马尔克斯的文学关系，不使用阿卡塔卡或哥伦比亚坐标代替。

地图默认只显示 `featured`，进入国家后显示 `eligible`；没有坐标的文学空间仍可通过卡片进入页面。前端不通过名称猜测国家归属，全部消费 `parent_place_id` 和 `map_relation_role`。
