## 2. 页面落地

| 页面层 | 落地规则 |
|---|---|
| 国家页 | 由 `place_kind=country` 和 `parent_place_id` 驱动，显示地点、关联作者和关联作品 |
| 现实地点页 | 显示地图状态、坐标精度、坐标来源和正式文学地点关系 |
| 虚构空间页 | 显示文学空间关系，不展示或推导现实坐标 |
| 完整作者页 | 仅对 `source_minimum_status=meets` 使用完整阅读入口，并列出创作关系 |
| 完整作品页 | 使用 `auto_approved` 一句话摘要，列出作者和地图/研究关系 |
| 研究缺口作品页 | 保留实体、关系、事实和来源；显示缺口提示，不生成确定性策展导语 |
| 关联节点页 | `#/node/{entity_id}` 作为研究回退，显示可回查关系和事实，不伪装成完整阅读页 |
| 作品集模块 | 在作者/作品关联区显示为研究节点，不单独扩展超出 V2 范围的集合页 |
