# V2.0.0-rc.3 Public UI QA

- 日期：2026-08-12
- 结论：**PASS**

## 扫描范围

对生成后的公共静态包执行两层检查：

1. 扫描 147 个 HTML 文件的可见文本，忽略脚本、样式、模板与数据键；
2. 在 Chromium、Firefox、WebKit 的桌面与 390px 手机页面中读取实际渲染文本。

扫描词包括版本/阶段词、内部 ID、研究和审核状态、数据字段、数据库与构建术语，以及“测试站”“当前样本”等开发语言。两层扫描均为 0 命中。

## 公共数据边界

部署构建不直接复制内部 `site_data.json`，而是生成约 224 KB 的公共数据包。该数据包：

- 不包含 `review_queue`；
- 不包含 `review_status`、`admission_status`、`source_minimum_status`；
- 不包含 `schema_version`、内部计数或 QA 对象；地图和实体路由仍保留最小机器字段，但前端只把它们转换成自然中文且从不直接显示；
- Presentation Layer 不包含待审状态或内部依据字段；
- 公众仍可查看自然语言事实和可读书目。
