## 三处指定修订

- 《星辰时刻》不再使用“迟钝于自己的不幸”，改为说明人物缺少解释处境的资源与语言，并保留对叙述者代言的审视。
- 《巴伦坎南》不再使用“两种世界在同一座村镇相遇”，改为“不平等的世界在同一片恰帕斯社会空间中并置”。
- 《光明世纪》导读使用“来自马赛的维克多·于格”，不在策展层锁定职业身份。

## 页面继续探索闭环

- 作家页：兴趣匹配 → 3 个关键词 → 作品 → 阅读路线 → 阅读问题 → 地点与主题。
- 作品页：低剧透导读 → 为什么值得读 → 专属读法 → 阅读问题 → 地点 → next-read。
- 地点页：文学导语 → 空间意义 → 具体探索路线 → 作家或作品。
- 首页：10 条策展路径均包含导语、至少 3 个有序目标及最终阅读问题。
