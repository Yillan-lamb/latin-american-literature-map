# 拉丁美洲文学地图 V2.0.0 发布候选说明

> 当前状态：`V2.0.0-rc.2`，整改后的发布候选；等待 `V2-N4` USER 正式发布批准。

## 本次实现

V2 将 V1 正式研究数据库转换为面向中文读者的交互式文学地图，完成核心闭环：

> 发现文学 → 认识作家 → 进入作品 → 沿文学关系继续探索

本候选版本包括：

- 地图主入口与国家 → 地点两级探索；
- 作者地理、作品故事空间和文学虚构空间三类地图语义；
- 作家、作品、国家、现实地点、虚构空间和研究关联节点页面；
- 完整搜索、类型筛选和文学时期时间线；
- 普通阅读层与研究证据层；
- 研究缺口、hold、user_review 和无坐标虚构空间的状态边界；
- 静态优先部署候选包与 GitHub Pages 手动部署工作流。

## 与 V1 的关系

V2 不替换 V1 Research Data。V1 主库继续作为来源、事实、关系、内容卡和审核状态的研究基线；V2 Geo Data 补充地图所需的坐标、父级和空间分类；Curation Data 只负责重点呈现和阅读入口；Web Data 负责网站消费。

当前 Web Data 统计：144 个实体、40 张内容卡、238 条事实、76 条正式关系、40 条 relation hold、13 个研究缺口、74 个来源、24 个地图数据行、25 条文学地点关系。
