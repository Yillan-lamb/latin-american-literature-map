## 2. 搜索

路由：`#/search`、`#/search?q=关键词`

- 搜索实体中文名、原文名和内容卡标题；
- 结果来自 `search_index`，不在前端维护名称清单；
- 结果可以进入作家、作品、国家或地点页；
- 空结果给出换词提示，不生成推测性结果；
- 输入框、提交按钮和结果链接支持键盘访问；
- 当前为基础客户端过滤，不引入后端搜索服务。

## 3. 时间线

路由：`#/timeline`

时间线采用“文学节点优先、历史背景从属”的结构：

- 作品节点消费内容卡的时期和首次发表/出版事实；
- 历史事件只有在 V1 已有事件实体时进入 Web Data，并保留当前审核状态；
- 每个节点可以继续进入作品页或对应研究层；
- 节点不生成独立地图层；
- `candidate_for_staging_review`、`card_period_only` 等状态在界面中保留，不被改写为确定性文学史结论。

## 4. 实际覆盖

当前 Web Data 时间线包含 28 个文学作品节点和 5 个历史背景实体节点。首页只展示前两个按年代排序的节点，完整时间线页面展示全部节点。
