# 研究方法与来源原则

本项目以“可追溯、可区分、可复核”为基本研究原则。

## 来源与证据

- 优先使用可靠出版物、学术论文、图书馆或文化机构资料及权威网页；
- 书籍至少记录书名，论文至少记录论文名，网页记录页面标题和 URL；
- 页码、章节、段落或版本信息在可获得且有助于复核时补充；
- 同一来源可以支持多条事实，但每条公开事实都应保存明确的来源关系；
- 来源不充分、事实冲突或解释强度不足时，内容进入 hold / review。

## 内容分层

项目区分四类内容：来源记录、研究事实与关系、证据与审核材料、面向读者的策展文字。研究过程中的“某机构列出、某记录确认”等证据语言不会自动成为普通页面文案；网页内容需要经过独立的 Reader Layer 转换和检查。

## 数据进入网站的原则

研究数据先完成实体规范化、来源映射和关系审核，再由构建程序生成 Web Data。前端负责呈现，不独立发明或维护文学事实。尚未通过相应范围审核的数据可以留在研究主库，但不会因此自动进入网站公开范围。

具体字段、维护与版本流程见 [数据模型与维护](../data/)；历史研究审核记录见 [`project/audits/research/`](../../project/audits/research/)。
