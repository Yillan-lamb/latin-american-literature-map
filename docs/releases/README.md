候选说明不等同于正式 Public Release。正式发布须通过数据、来源、版权、Web、部署和安全门禁，并获得 USER 明确批准。

Research Data、Research Schema、Web Data schema 和 Web Product 独立编号，路径整理或文档变更不自动触发数据/Schema 升级。正式审计见 [`project/audits/`](../../project/audits/)，历史审计见 [`project/archive/audits/`](../../project/archive/audits/)；当前公开版本事实由根目录 [`README.md`](../../README.md)、数据/Web manifest 和对应 CHANGELOG 条目提供。
