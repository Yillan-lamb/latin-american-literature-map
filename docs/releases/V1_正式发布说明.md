# 拉丁美洲文学地图 V1.0.0

拉丁美洲文学地图 V1.0.0 是面向中文读者的可追溯文学内容数据库首个正式版本。

## 主要内容

- 10 位核心作家、30 部核心作品；
- 74 项正式来源、144 个规范实体；
- 76 条经审核关系、40 条关系 hold；
- 238 条事实素材、40 张内容卡；
- CSV、JSON、SQLite 和 18 工作表 Excel 四种同源格式；
- 来源目录、数据字典、质量报告及可重复构建验证脚本。

Schema 0.3 包含 13 个受控关系词，其中 `BASED_ON_EVENT` 仅允许 `work → event`。V1 最低关系门槛为 75，当前为 76；150 条是 V1.1 扩展目标。

## 质量与边界

最终审计为 0 errors、0 warnings；SQLite 完整性与外键检查通过，Excel 公式错误为 0，来源与实体引用零悬空。发布不包含原书、整书 OCR、论文全文、凭据、inputs 或其他受限材料。

40 条关系 hold、研究缺口、政治诗歌证据边界、《消逝的足迹》年份 hold 和 author→event 说明级问题均保留在 `docs/releases/V1_已知问题.md`。网站、小程序、地图、时间轴和展览交互不属于 V1，留待 V2。
