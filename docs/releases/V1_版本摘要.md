# 拉丁美洲文学地图 V1 版本摘要

状态：V1.0.0 正式版

V1 建立了面向中文读者的可追溯拉丁美洲文学内容数据库，覆盖 10 位核心作家、30 部核心作品、74 项正式来源、144 个规范实体、76 条经审核关系、238 条事实素材和 40 张内容卡。

## 这一版完成了什么

- 建立 CSV、JSON、SQLite、Excel 四种同源交付格式。
- 建立来源、实体、关系、证据、事实、卡片和缺口之间的可追溯关联。
- 覆盖约 7 个国家或地区、至少 3 位女性作家，并纳入葡萄牙语文学。
- 把作品、作品集、版次、译本、改编、人物、地点、事件、运动和主题分层建模。
- Schema 0.3 包含 13 个受控关系词；新增 `BASED_ON_EVENT` 严格限定为 `work → event`。
- 对单来源解释性关系、研究缺口和政治诗歌证据不足保持 hold/gap，没有为满足数量而补写或确定化。

## 质量结果

- V1 关系门槛：76/75，已满足；150 作为 V1.1 扩展目标。
- SQLite 完整性：ok；外键错误：0。
- Excel：18 个工作表；公式错误：0。
- CSV/JSON/SQLite 行数与主键一致；来源和实体引用零悬空。

V1 交付的是内容数据库，不包含网站或小程序。数字文学地图和展览开发属于 V2。
