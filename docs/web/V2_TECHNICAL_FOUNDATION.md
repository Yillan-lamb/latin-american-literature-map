# V2 技术选型与网站基础框架

## 1. 任务信息

- 任务：`V2-S4-001`
- 日期：2026-08-11
- 状态：`✅ DONE`
- 技术方向：静态优先、Web Data 驱动、无后端依赖
- 网站目录：`site/`

## 2. 选型

N2 采用轻量静态单页框架：`index.html + styles.css + app.js`。不引入运行时后端，不在前端硬编码研究事实，浏览器启动后通过相对路径读取 `data/v2/web/site_data.json`。

这样选择的理由：

- 适配 V2 静态优先范围，构建链路短，便于 GitHub Pages 或其他静态托管；
- 当前没有既有前端工程或锁定的框架依赖，避免 N2 为工具链引入不必要的外部状态；
- Web Data 已经是页面消费层，原型可以直接验证数据结构、地图语义、页面路径和阅读/研究双层；
- 后续如果 N2 审核通过，可以在不改变 Web Data 契约的情况下迁移到 React/Next 等组件框架。

## 3. 路由骨架

通过 hash 路由实现静态托管兼容：

- `#/`：首页；
- `#/country/{place_id}`：国家页与国家→地点路径；
- `#/place/{place_id}`：现实地点页或文学虚构空间页；
- `#/author/{entity_id}`：作家页；
- `#/work/{entity_id}`：作品页；
- `#/search`：基础搜索；
- `#/timeline`：时间线。

## 4. 设计系统

- 背景：暖纸色与深墨色，模拟文学杂志和档案纸张；
- 强调色：珊瑚红用于故事空间与行动入口，靛蓝用于研究层，墨绿用于现实地点；
- 标题：衬线字体栈；正文：系统无衬线字体栈；不依赖外部字体 CDN；
- 组件：站点头部、地图板、地点节点、作品卡、研究层折叠面板、时间线、搜索结果；
- 交互：键盘可达、可见焦点、`prefers-reduced-motion` 降级、窄屏单列布局；
- 图片策略：N2 不使用未经许可的图片；以排版、色块、地图节点和档案式信息块完成视觉验证。

## 5. 已建立的基础

- `site/index.html`：应用壳、导航和语义容器；
- `site/styles.css`：设计系统、响应式布局、地图板和双层阅读样式；
- `site/app.js`：Web Data 加载、hash 路由、首页/国家/地点/作家/作品/搜索/时间线渲染；
- 入口数据：`data/v2/web/site_data.json`；
- 构建与 QA：`scripts/build_v2_web_data.py`、`scripts/validate_v2_web_data.py`。

## 6. 验收边界

本任务只固定技术基础和可运行的路由骨架。首页、两级地图、页面模板、搜索与时间线的完整交互分别在 `V2-S4-002` 至 `V2-S4-004` 继续验收；N2 之前不扩展用户系统、CMS、3D 地图或 AI 问答。
