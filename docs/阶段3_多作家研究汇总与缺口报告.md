## 2. 覆盖结果

- 地域：墨西哥、哥伦比亚、阿根廷、古巴、秘鲁、智利均有批次覆盖。
- 性别：阶段 3 纳入埃莱娜·加罗和罗萨里奥·卡斯特利亚诺斯；女性作家总量在阶段 4 覆盖审计中继续按章程核算。
- 体裁：长篇、短篇/短篇集、诗集和单篇诗均建立分层候选；三部聂鲁达诗集统一按 `collection` 处理。
- 语言：阶段 3 以西语研究为主；阶段 2 已用李斯佩克朵的葡语来源补入巴西与葡语维度，阶段 4 需从全项目口径而非单批次口径复核。
- 关系：59 个关系组具备进入暂存审核的条件；29 个单来源解释性关系继续 hold，不为追求数量降低证据门槛。

## 3. 尚未解决的缺口

1. 部分人物生卒年、作品首发年、诗集分卷信息和历史事件基础值缺少直接权威来源。
2. 32 条查重候选需要跨 S1、N2 暂存和三个批次统一归并；同名作品、人物、作品集和改编不得仅按字符串合并。
3. `BASED_ON_EVENT` 尚不在 Schema 0.2；卡努杜斯等历史事件联系暂以事实和问题项保留。
4. 29 个解释性关系仍缺第二个独立合格来源；政治诗歌主题尤其不得从作者总体标签自动下推到具体诗集。
5. 来源候选尚未统一分配正式 SRC 编号，候选实体、关系和卡片也尚未完成全局暂存 ID 映射。

## 4. 阶段 4 工作流

阶段 4 使用“大包执行、关键门禁审核”的方式推进：

1. `V1-S4-A01`：权威基础事实、历史事件关系证据和政治诗歌主题证据的合并补证包，由外部 AI 执行。
2. `V1-S4-A02`：全局译名、别名、重复实体、类型冲突和正式来源编号的机械规范化包，由外部 AI 生成候选，Codex 裁决。
3. `V1-S4-A03`：关系词统一、hold 补证结果和 Schema 兼容性评估，由 Codex 主导；任何 Schema 变更进入用户节点。
4. `V1-S4-A04`：30 部作品内容卡事实汇总与国家、语言、性别、时代、体裁、主题覆盖审计。
5. Codex 生成 V1 候选 SQLite/CSV/JSON、数据字典、来源目录和 N3 审核包。

## 5. 准入边界

阶段 3 的 `pass` 是候选层门禁，不是主数据库准入。只有经过全局消歧、来源编号、关系词兼容、引用完整性和暂存验证后，数据才可进入 V1 候选包。

公开仓库只保存治理文档、书目级信息、结构化候选、评审和汇总；原书、论文全文、整书 OCR、inputs 和 local_only 材料继续排除。
