日期：2026-09-13

## 共用母版

- 刊头：大型 `LATAM` + 中英双语刊名；右侧以杂志目录式双行导航呈现，当前页用酒红细线标识。
- 版面：暖纸底、深墨正文、酒红标题、深蓝图版，主要依靠分栏与细线组织，不使用统一圆角卡片。
- 图像：只使用已登记的本地肖像与项目自有生成资产；摄影统一做旧，装饰层允许裁切、压边与重叠。
- 收尾：母版页面共享植物／山体档案横幅与中西双语品牌引言。

## 页面映射

1. 首页：45/55 封面双栏 → `PLATE 01` 地图图版 → 阅读路径／重要作家／文学趣闻三栏 → 品牌横幅。
2. 作家目录：完整 25 位公开作家，两栏档案图版、放大的肖像、稳定排序与即时目录过滤，不分页截断。
3. 作家详情：全部 25 条公开路由使用超大姓名 + 人物档案拼贴 + 五段横向目录 + 生平、代表作品、地点、主题与可展开趣闻；博尔赫斯保留专属构图。
4. 作品目录：完整 62 部公开作品／合集，使用策展版封面、书目信息与阅读导语，并支持目录内过滤。
5. 作品详情：全部 62 条公开作品／合集路由使用左侧作品信息 + 右侧作者／档案拼贴 + 概览、阅读价值、地点、主题、阅读方法、相关阅读图版网格；《百年孤独》保留专属构图。
6. 文学趣闻：大标题 + 马尔克斯主故事 → 四则不等宽剪报 → 作家头像索引。
7. 时间线：标题与文化图像 Hero → 作家／作品筛选 → 87 条公开记录横向年代轴；所有记录保留在 DOM，窄屏保持内部横向滑动。
8. 搜索：完整 127 条公开文学入口，按八类分组展示；支持中文名／原文名即时搜索和类型筛选，不再只展示少量结果。
9. 关于项目：标题与档案拼贴 Hero → 01—06 报刊分栏，分别承载项目介绍、动机、探索结构、数据方法、使用方式和来源边界。

## 不变边界

- 不修改 `site/`、Research/Curation/Web Data、实体 ID、路由、公开/hold 逻辑或地图真实/虚构空间区分。
- 国家、地点、阅读路径和其他探索节点继续使用既有渲染器；本轮不宣称这些路由已经完成正式视觉集成。
- 桌面视觉以 1440×900 为主，另验证 390×844；移动端保留纸面、超大标题、拼贴和编辑分栏语义。
