## 2. 已实现

- 首页以地图作为第一入口，随后展示 N2 精选作者与作品；
- 国家层使用 Web Data 的 `place_kind=country` 和 `map_status`；巴西使用 V2 技术父级，墨西哥与哥伦比亚使用 V1 国家实体；
- 点击国家后，通过 `parent_place_id` 展示下级地点，不在前端维护国家—地点硬编码表；
- 现实地点、虚构文学空间、国家入口使用不同视觉语义；
- 现实地点可以打开地点页并显示坐标精度、来源 URL 和文学关系；
- 虚构空间可以打开文学空间页，但不会出现现实坐标；
- 地图筛选支持全部、现实地点、虚构空间；
- 精选作者和作品全部来自 `Curation Data → Web Data`，首页不直接写研究事实；
- 无坐标的文学空间仍通过卡片进入页面，避免“没有坐标就没有文学空间”；
- 移动端将地图、筛选器和卡片降级为单列布局，按钮保持可触达。

## 3. N2 交互路径

```text
首页
 ├─ 国家层地图
 │   ├─ 巴西 → 里约热内卢 → 《星辰时刻》
 │   ├─ 墨西哥 → 恰帕斯 / 科米坦 / 科马拉
 │   └─ 哥伦比亚 → 阿卡塔卡 / 马孔多
 ├─ 精选作者 → 作家页
 └─ 精选作品 → 作品页
```

地图中的文学关系由 `map.relations` 驱动；国家归属由 `parent_place_id` 驱动；“精选”由 `curation.selections` 驱动。前端只负责呈现和路由。
