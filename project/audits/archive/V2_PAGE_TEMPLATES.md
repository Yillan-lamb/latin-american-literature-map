## 2. 页面模板

| 模板 | 路由 | 数据入口 | N2 样本 |
|---|---|---|---|
| 国家页 | `#/country/{place_id}` | `map.places`、`map.relations`、`parent_place_id` | 巴西、墨西哥、哥伦比亚 |
| 现实地点页 | `#/place/{place_id}` | `map.places`、`map.relations`、坐标来源 | 里约热内卢、恰帕斯、科米坦、阿卡塔卡 |
| 文学虚构空间页 | `#/place/{place_id}` | `map.places`、`map.relations`、虚构空间策展记录 | 科马拉、马孔多 |
| 作家页 | `#/author/{entity_id}` | `pages.authors`、内容卡、CREATED 关系 | 4 位 N2 作者 |
| 作品页 | `#/work/{entity_id}` | `pages.works`、内容卡、地点关系 | 6 部 N2 作品 |

国家页和地点页共用部分地点卡，但不是同一个事实来源：国家归属消费 `parent_place_id`，文学关系消费 `map.relations`，坐标消费地点技术字段。

## 3. 双层阅读

每个作者页、作品页和有 V1 实体 ID 的地点页均提供“展开研究层”面板：

- 阅读层：策展导语、作品卡、地点导语、轻量关系描述；
- 研究层：事实字段、事实审核状态、正式关系、关系审核状态；
- 不确定内容：保留 `candidate_for_staging_review`、`research_gap` 或 `hold`，不自动改写成确定性导语；
- 来源路径：Web Data 保留研究引用 ID，后续可继续接来源详情和原始定位。

## 4. 模板规则

- 现实地点页显示坐标精度和来源 URL；没有可靠点位时显示“未落点”，不补猜；
- 虚构空间页显示文学空间标识，不显示现实坐标，也不把现实同名地点作为默认地图点；
- 作家页只列 V1 `CREATED` 关系对应作品；作品页只列正式关系对应作者和地点；
- 国家页没有通过实体名称猜测作者或作品，全部从 Web Data 的地点关系和层级字段计算；
- 研究层不会因为策展推荐而生成正式关系；
- 页面内容为空时显示温和的缺口提示，而不是填入生成性事实。

时间线模板以作品首次发表/出版事实或内容卡时期为主轴，历史事件节点保留其当前审核状态并弱化为背景层。
