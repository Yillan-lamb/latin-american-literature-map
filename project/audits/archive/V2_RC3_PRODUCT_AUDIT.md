# V2.0.0-rc.3 产品一致性审计

- 审计日期：2026-08-12
- 最高依据：`project/plans/V2_网站产品决策与开发总说明书.md`
- 审计对象：实际生成的公共网站，而非代码存在性或历史节点结论
- 结论：**通过内部产品门禁，提交 V2-N4 USER_REVIEW**

## 审计方法

本轮没有把 PR #4、rc.2 或 N3 历史通过视为产品完整证明。审计从普通中文读者的实际路径出发，逐页核对生成后的首页、地图、作家、作品、地点、搜索、时间线、研究层、静态路由与移动端。既有 Research / Geo / Curation / Web Data 架构和已审核事实没有重建；变化集中在 Presentation Layer、公共静态包和发布门禁。

## 产品闭环模拟

普通读者可以完成：

`首页地图 → 墨西哥 → 科马拉 → 胡安·鲁尔福 → 《佩德罗·巴拉莫》 → 延伸到《百年孤独》 → 展开资料来源`

这条路径只要求理解国家、地点、作家、作品、文学主题和来源，不要求理解任何项目版本、内部数据字段或审核状态，符合“发现文学 → 认识作家 → 进入作品 → 沿文学关系继续探索”的核心闭环。

## 保留且未被破坏的成果

- V1 主数据库及已审核事实、关系、hold、research gap 均未为了前端被改写；
- Geo Data 的现实/虚构/未知分类和虚构空间无坐标规则保留；
- Curation Data 的既有自动准入、待审与 hold 记录保留；
- 新阅读路径、价值判断与时期划分只进入独立 Presentation Layer；
- 未加入账户、评论、CMS、AI 问答、3D 地图、复杂 GIS 或作品封面。

## 已知产品限制

- 地图底图采用 Natural Earth 1:110m，适合区域探索，不适合精细海岸或城市级 GIS 分析；
- 当前有内容状态的国家为 7 个，其他真实国家边界用于建立区域认知但尚无可进入内容；
- 17 部完整作品已有“为什么值得读”，3 部研究缺口作品继续以资料不足处理；
- 10 条延伸阅读只覆盖核心路径，不为每部作品强行推荐；
- 作家照片不是本轮阻断项，rc.3 未加入无法确认许可的图片；
- 正式 canonical、sitemap URL 依赖用户确认生产 HTTPS origin；目前仅验证生成能力，没有部署。
