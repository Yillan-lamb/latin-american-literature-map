# 03_SCOPE_AND_COVERAGE_POLICY_RESEARCH — “拉丁美洲地图”的范围定义与两层覆盖模型

## 1. 问题

网站名为 **拉丁美洲文学地图**（About 页亦自我表述为 a literary map of Latin America）。但下列概念互不相同，底图与交互范围必须分别定义：

| 概念 | 覆盖 | 与本站关系 |
|---|---|---|
| Latin America（拉丁美洲） | 罗曼语系（西/葡/法）殖民历史塑造的美洲地区：墨+中美+说拉丁语的南美+说法语的加勒比（海地）及法属加勒比 | 站名本体 |
| South America（南美洲） | 大陆地理分区（含圭亚那/苏里南，不含中美/墨西哥） | 子集 |
| Caribbean（加勒比） | 地区概念，含大量英语/荷兰语区 | 交叉 |
| Ibero-America（伊比利亚美洲） | 西+葡语国家（**不含海地/法属**） | 比站名窄 |
| Hispanic America（西语美洲） | 仅西语国家 | 更窄 |

**既有 USER 决策（必须遵守）**：项目决策记录（DEC-007 系，2026 年 V1 阶段）明确项目正式采用「拉丁美洲文学地图」——**不是仅限南美洲**；作家范围、地域模型与地图按拉丁美洲设计。

> ⚠️ **范围口径元决策（Gate C-8，本修订版显式转交 USER）**：UN M49 官方统计分区确实设「Latin America and the Caribbean」（含 Caribbean / Central America / South America 子区，本会话访问 unstats.un.org/unsd/methodology/m49/ 确认）。但 **M49「Latin America and the Caribbean」≠ 站名「拉丁美洲」**：前者含英语/荷兰语加勒比，而「拉丁美洲」的本义是罗曼语（西/葡/法）殖民历史塑造的美洲（见 §1 表 03:9 vs 03:11）。因此不能用「与站名口径一致」直接把 L1 推到整个 LAC；站点 L1 究竟取「Latin America」还是「UN M49 LAC」、以及属地/相邻陆地如何纳入，须由 USER 在 Gate C-8 圈定后再回填 08 各行布尔值。

## 3. 两层模型：BACKGROUND GEOMETRY vs LITERARY INTERACTIVE SCOPE（推荐采纳）

> **一个地区可以作为完整地理底图存在（L1），但不自动进入文学交互范围（L2）。**

- **L1 背景几何层（条件模型）**：凡位于 USER 尚未裁决的 C-8 口径（`Latin America` 或 `UN M49 LAC`）内的陆地，才进入「完整呈现」分支。C-8 未裁决前，任何 `TRUE`/“一律”均不得视为授权；候选范围内的无文学数据者拟用中性非强调色，图例注明「当前暂无收录作家或作品」。**底图完整性的理由是地理事实，但本包不代替 C-8 决策。**
- **L2 文学交互层**：在 C-8 选定 L1 前提成立后，可点击、有中文标签、有国家页的国家/地区才按**文学收录事实**决定（该语言区作家是否进入 Research public scope），由内容任务（WCD-04/05/07 系）驱动，不由 WCD-09 单方决定。交互层的扩张（如波多黎各、特立尼达、马提尼克）属内容决策，分别引用 08 的 C-n。

两层模型直接化解三个误区：①不因「是否拉丁语有争议」删除圭亚那/苏里南/伯利兹；②不因「没有文学数据」让海地/牙买加/多米尼加从底图消失（当前实现已正确保留其几何——**保持**）；③不因「法国是欧洲国家」预先决定法属圭亚那；当前实现**未**保留，是否补入须待 C-8/C-3 选择后按 A-1/CH-02 条件实施。

## 4. 对欧洲「作家地理」的处理（马德里/巴黎）

Web data 含西班牙/法国两个 hidden 国家与马德里/巴黎两个 eligible 城市点（作家流亡/创作地理，如科塔萨尔—巴黎）。当前 viewport（33°N 封顶）把二者裁出画外，产生「不可见但可聚焦」元素（01 §4 item 4）。

选项（建议在 C-8 及相关 C-n 一并裁决）：
- **A（推荐）**：维持 viewport 不变（拉丁美洲为主体）；马德里/巴黎改为**非地图交互入口**（仅在作家页/关系列表中出现，地图上不渲染点），或渲染为图外列表芯片。地理诚实、无裁切伪影。
- B：扩展 viewport 至欧洲 → 拉美被压缩，违背「地图为主入口」的产品定位，不推荐。
- C：多视图（主图 + 欧洲流亡小图/box）——实现成本高，后续再议。

## 5. 建议的范围判定规则（供 12 收敛）

1. L1 底图收录判定 = 「位于 Gate C-8 圈定的 L1 口径（`Latin America` 或 `UN M49 LAC`）地理范围内，或与该口径直接相关的相邻陆地」；未圈定前，此规则仅是候选草案，不构成已授权范围；
2. 主权争议地区（福克兰等）在 L1 以**争议中性样式**呈现，不因争议从底图消失，也不做归属暗示（样式建议见 05）；
3. L2 交互判定 = 「web data 中存在该国家/地区的公开文学数据（作家/作品/地点关系）」，数据空缺不构成删除理由；
4. 范围外的相邻陆地（美国南部、南乔治亚、西非、欧洲）仅作为 C-8/C-4/C-7 的候选 keep-out 记录；未裁决前不把“不渲染”写成已授权事实，最终结果须在图例/关于页说明。
