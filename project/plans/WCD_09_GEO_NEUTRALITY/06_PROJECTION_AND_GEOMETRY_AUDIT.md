旧站点 viewBox 下 1 像素约等于 0.1587°纬、约 **17.7 km** 的南北距离；因此南北方向 **>17.7 km** 才大致达到 1 像素。经度方向距离随纬度变化，不能用统一的 10 km 阈值代替（也就是不能用 10 km 作为统一像素门槛），必须按纬度换算。

## 2. 指标定义（整改后的唯一口径）

所有数值以球面半径 `R=1`、经纬度先转弧度计算。对投影平面函数 `P(lambda, phi)`，固定 `h=0.25°` 中央差分构造局部单位球正交基的 Jacobian 两列：

```text
j_lambda = [ P(lambda+h,phi) - P(lambda-h,phi) ] / (2*h*cos(phi))
j_phi    = [ P(lambda,phi+h) - P(lambda,phi-h) ] / (2*h)
J = [ j_lambda  j_phi ]
```

- `ew_ns_scale_ratio = ||j_lambda|| / ||j_phi||`：东西向/南北向局部尺度比，仅是**方向代理**；它可以小于 1，不能代表完整形状。
- `principal_axis_ratio = smax(J) / smin(J)`：对完整 `J` 求奇异值，包含基向量非正交、旋转和剪切造成的形变；这是完整局部形状失真，按定义必须 `>= 1`。
- `area_factor = abs(det(J))`：投影平面相对于单位球正交微元的原始局部面积因子；不由画布 `preserveAspectRatio` 或统一 fit 推断。
- `area_factor_relative_to_center = area_factor / area_factor(center)`：仅用于消除各投影统一尺度约定、便于跨候选看相对中心变化；它不是 `area_factor` 的替代字段。

因此，不能再把 `ew_ns_scale_ratio` 叫作 shape 指标，也不能把相对中心面积值写成绝对面积因子。`07_PROJECTION_SAMPLE_METRICS.csv` 的每行均记录这四个数值字段和上述计算方法。

## 5. 结论与 B-1 建议

1. 当前映射违反 TASK-099「保持权威参考的投影、坐标范围、地理轮廓和宽高比例」门禁，P0，必须替换。
2. **LAEA 仍是综合首选，但理由不是“形状最优”**：它保持 `area_factor≈1`（等积）且 `principal_axis_ratio` 全窗最大约 1.327，满足面积中立目标并保持可接受轮廓；方向代理可低于 1，不能作为完整形状结论。
3. **AEQD 的完整主轴比确实更好**（最大约 1.205492），但面积因子从中心 1 增至蒂华纳角约 1.205491，最多约 +20.5%；若 USER 选择 AEQD，CH-07、CH-24 必须按 AEQD 自身的 `principal_axis_ratio` 与 `area_factor` 范围验收，不得套用 LAEA。
4. Equirect 是改动最小的 fallback，但高纬 `principal_axis_ratio/area_factor` 仍达 1.667147。Equal Earth、Natural Earth I、Albers、Mercator 的完整七点表见 `07_PROJECTION_CANDIDATES.csv`；前两者虽可数值计算，主图综合性不如 LAEA，Albers 跨赤道形变大，Mercator 面积不诚实。
5. 等比画布只证明浏览器没有二次非等比缩放，不能证明投影等积或形状无失真。换投影后 `LABEL_OVERRIDES`、8 处 CSS 藏标签和出画点必须分别按 CH-08、CH-09、CH-10、CH-11 重导/复核。
