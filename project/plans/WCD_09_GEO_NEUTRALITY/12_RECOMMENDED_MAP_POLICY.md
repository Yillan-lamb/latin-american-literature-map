## 1. 政策总纲（一句话版）

**C-8 未裁决前，本包不把任何宽范围写成既定授权：L1 只提供 `Latin America` 与 `UN M49 LAC` 两个条件分支；在选定分支内才要求完整背景几何，L2 仍由收录事实单独决定。投影、争议呈现、许可与坐标工作项均保持条件式门禁。**

三个不变式（任何实施不得破坏）：

1. **在 C-8 选定的 L1 范围内，没有文学数据 ≠ 从地图上消失**——L1 完整性以地理事实为准（03 §3）；
2. **争议或未决勘界存在 ≠ 替某一方作结论**——中性样式、D-2 线型、D-3 逐案处置和 D-4 通用披露分别决策，不做主权裁决（05 全部 20 案例）；
3. **虚构空间 ≠ 现实坐标**——虚构地点永不落现实经纬度（现状已由构建器强制，保持；01 §3）。

### 3.2 L2 文学交互层

判定标准 =「在 C-8 选定 L1 前提成立后，web data 中存在该国家/地区的公开文学数据」。当前实现有 **13 个可交互唯一国家 code**；巴西的两个重复实体不能被算作两个国家。C-8 及相关 L2 决策未落地前，08 以 `CONDITIONAL_ACTIVE`/`CONDITIONAL_NON_INTERACTIVE` 表示候选状态；海地/多米尼加/巴哈马等 C-1 项不得预填成授权交互。**数据空缺不构成删除理由，也不构成自动交互理由。**

### 3.3 Viewport 与出画地点（03 §4）

推荐 **选项 A**：viewport 维持不变（拉丁美洲为主体）；马德里/巴黎两处出画点（`px=[1169.6,-46.7]`、`[1231.5,-99.8]`，01 §4 item 4）改为**非地图交互入口**（作家页/关系列表呈现，地图上不渲染为可聚焦元素），消除 WCAG 2.4.7「不可见但可聚焦」风险。选项 B（扩 viewport 至欧洲）违背产品定位，否决；选项 C（欧洲流亡小图）成本高，留观。

## 4. 投影政策（采纳 06/07 定量结论）

**综合推荐：Lambert 方位等积（LAEA），中心 (75°W, 11.5°S)，等比缩放适配画布。** 这不是“完整形状最优”的断言：AEQD 的 `principal_axis_ratio` 最大值更低，但它牺牲面积中立性。B-1 仍由 USER 裁决，任何候选在裁决前都不锁定为实现。

指标口径固定为：`ew_ns_scale_ratio` 是局部单位球正交基两列范数比（方向代理，可小于 1）；`principal_axis_ratio=smax(J)/smin(J)>=1` 是含非正交/剪切的完整局部形状失真；`area_factor=abs(detJ)` 是原始局部面积因子；另列 `area_factor_relative_to_center` 只用于消除统一尺度、观察相对中心变化。全部使用固定 `0.25°` 中央差分 `J=[P_lambda/cos(phi),P_phi]`，详见 06 §2 和 `07_PROJECTION_SAMPLE_METRICS.csv`。

|---|---|---:|---:|---:|---:|---|
| 现状（各向异性线性） | **REPLACE** | 1.659562–2.766735 | 1.659562–2.766735 | 1.659562–2.766735 | 1.000000–1.667147 | 完整主轴失真随纬度增大，违反比例门禁 |

| Equirect φ1=−11.5° | FALLBACK (RECOMMENDED-2) | 1.000000–1.667147 | 1.000000–1.667147 | 1.000000–1.667147 | 1.000000–1.667147 | 实现最简单，但高纬面积和形状膨胀是结构性代价 |

## 5. 中立性呈现政策（采纳 05 全部 20 案，按 D-2/D-3/D-4 与 C-n 条件收敛）

1. **通用免责声明**（措辞经 **D-4** 择定，13 §1 候选 D1/D2/D3）：地图页/About 页固定区域展示，点名来源（Natural Earth/GeoNames）、申明不代表对争议边界/归属/地位的立场——**不称来源为「中性权威」**（M-07；来源选择含事实决策）。
2. **RISK-01 福克兰（马尔维纳斯）**：tooltip/图例用双名；**次序与符号经 D-1 + 官方名源核验**（10 NAME-06；本包不预设次序；斜杠可弱化层级，但先后顺序仍可能产生显著性，USER 仍须定序）。当前 EN-only tooltip 必须消除。
3. **RISK-02 埃塞奎博、RISK-03 伯利兹-危地马拉、RISK-19 萨波迪亚礁、RISK-20 南巴塔哥尼亚冰原勘界段等**：维持 de facto/基础线为基线；「solid de facto 线 + 通用免责」是否足够属逐案政策判断（**D-2 控制线型；D-3 控制逐案注记/处置**），需结合 16 的证据状态评估，不由通用免责替代。RISK-20 不得将普通实线描述为最终勘界完成。
4. **无 maritime/EEZ 层**；未来若加，逐层过 D-2/D-3 及其余争议案对应裁决项。
5. **法属圭亚那如按 C-3/C-8 实施**，可依已核验的 Guyane 行政分类和选定 France polygon/part 作法国行政关联背景，不作为独立国家配色；这不裁决边界、主权或范围，也不替代瓜德罗普/马提尼克的 `CANNOT_VERIFY`（NAME-29）。
6. **对比度/色盲专项验证**留 09E 实施（01 §5 标注未验证项）。

## 6. 坐标与数据政策（采纳 09）

1. 16 个 PASS_EXACT_DELTA0 地点保持现状值（本会话 GeoNames RDF 逐一复核 Δ=0–4m；**含 1 个 locality 阿卡塔卡，其余 15 为城市**，非「16 城市点」）；
2. **弱引用修复**：10 个可定位弱引用在 A-2 通过后换**永久 GeoNames ID**；V1-ENT-0052 恰帕斯是第 11 个弱引用但保持 `BLOCKED_CANNOT_VERIFY`，找到并核验正确永久实体前不得转换或 promote；**6 个已是永久源的只做 URL 规范化**（09 逐行 recommendation 列；M-04 重建清单）；
3. 恰帕斯（V1-ENT-0052，`BLOCKED_CANNOT_VERIFY`）保留 source 页 0 bytes 和当前坐标；不得编造永久 ID、不得强制转换，数据层变更须走 A-2；
4. **巴西双实体处理**（P1）：`V2-GEO-BR` 与 `V1-ENT-0183` 的合并或 canonical mapping 由 CH-12 实施时选择并验证，当前不视为已决定；
5. 虚构空间 3 处维持 no-coordinate（构建器强制），阿什格罗夫维持 hidden。
