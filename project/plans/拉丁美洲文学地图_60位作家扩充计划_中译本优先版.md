# 拉丁美洲文学地图：60+作家分批扩充计划（中文展示名优先版）

- **规划版本**：1.1
- **制定日期**：2026-08-18
- **修订日期**：2026-08-19
- **适用阶段**：V2 / `WEB-CONTENT-EXPANSION`
- **当前作家基线**：10 位
- **目标**：不少于 60 位作家
- **批次上限**：每批 3 位新作家；新作家各 3 部代表作；另补已有作家作品 11 部；每批新增作品总量不超过 20 部
- **预计批次数**：17 批
- **理论完成规模**：10 + 17×3 = **61 位作家**
- **核心流程**：Research → Research Review → SQLite → 必要的 Geo/Curation → Web Data → Frontend
- **本版核心修订**：“中译本优先”只要求网站展示时优先采用通行中译名；不要求每批完整考据译者、出版社、出版年份或 ISBN，也不以这些版本字段阻断文学空间扩充。

---

## 一、为什么采用“中文展示名优先”

本网站面向中文读者，因此作品页面应优先显示中文读者熟悉、能够辨认的通行中译名；原文题名则始终保留，作为实体查重和研究追溯的稳定锚点。

本计划因此由原来的“文学史知名度优先”调整为：

> **文学史地位 / 国际知名度 + 国别与时代代表性 + 文学空间价值 + 中文进入便利度**

“有中译本”可以帮助安排批次优先级，但不是 Research Data 的事实证据标准，也不是实体或作品准入的硬门槛。本阶段的首要目标是先把拉丁美洲文学空间展示出来。

### 1. 中文可读性优先级（非准入门槛）

新作家优先满足以下任一条件：

- **T1：强中文可读性，适合优先展示**
  - 至少有 3 部完整作品已有简体中文正式出版；
  - 或一个正式中文合集完整收录其 3 部以上代表作品。
- **T2：已有中文进入路径**
  - 至少有 1—2 部简体中文单行本；
  - 另外的代表作已有正式中文合集、旧版译本、繁体中文译本或可靠译介基础；
  - 执行批次时只需确认用于展示的中文通行名，不做完整版本审计。
- **T3：中文译介较少，但仍可进入文学空间计划**
  - 当前仅能稳定确认 1 部中文作品，或中文译介非常零散；
  - 是否进入排期主要由文学史、国别、时代和地图覆盖价值决定；中文版本不足本身不构成 HOLD。

T1/T2/T3 只用于排序和读者入口设计，不决定 Research PASS/HOLD，也不要求每位作家机械满足若干部完整中译本。

### 2. 豆瓣的用途

豆瓣、出版社页面、国家图书馆/高校书目等可以用于快速确认：

- 是否存在中译本；
- 中文读者通常使用哪个作品名；
- 必要时，一本中文合集是否覆盖目标作品。

译者、出版社、出版时间和 ISBN 在本阶段均为**可选补充字段**：检索时顺手可得可以登记，但不单独投入大量时间，不因缺失而阻断实体、事实、关系、卡片或 Web Data。

但豆瓣**不得作为文学事实、作品主题、作家影响关系等 Research Data 的正式研究来源**。这些内容仍应按项目既有规则使用原著、学术专著、论文、出版社、图书馆等可靠来源。

### 3. 为什么不能把 17 批完全锁死

中文译介仍在快速变化。作家出版社与中国外国文学学会西班牙葡萄牙语文学研究分会自 2024 年起启动“新拉丁美洲文学丛书”，其明确目标之一就是重印旧译、补译经典作家代表作和填补中文世界的译介空白。

因此：

- **Batch 01—05：硬计划**
- **Batch 06—10：高优先计划**
- **Batch 11—16：中期计划**
- **Batch 17：动态收口批次**
- 每完成 5 批做一次 `coverage + Chinese display-name consistency audit`，重点检查文学空间覆盖和中文展示名一致性；不做全量版本书目考据。

# 三、执行规则

每个批次开始前必须完成一次 `Batch Preflight`：

1. 从 `V1_MASTER.sqlite` 查询作者和作品，防止重复建实体；
2. 查询现有 `CREATED` 关系，防止重复建关系；
3. 对本批实际选中的作品确认原文题名和中文展示名；
4. 每部作品最低登记：
   - 原文题名；
   - 中文通行名或暂定展示名；
   - `display_name_status = published_title / common_title / provisional_title / no_known_translation`；
   - 支持该中文名称的页面或书目线索（能快速确认时）。
5. 译者、出版社、出版年份、ISBN 仅在现成来源直接可见或需要解决同名/异名冲突时登记；这些字段为空不触发作品替换或 HOLD；
6. 只有中文名称歧义可能造成错误实体合并、同名不同作或严重误导时，才暂停该展示名并交 Reviewer；
7. 再进入正式 Research change set；
8. Research Reviewer 通过后写入 SQLite；
9. 有地点意义的内容再进入 Geo；
10. 只有产品架构确有需要时才制作最小 Curation；
11. 最后重建 Web Data，不在前端硬编码文学事实。

> **注意：下表中的“已有作家追加 11 部”属于规划候选池，不是无需审核即可入库的固定事实。是否替换由文学研究证据、去重和批次范围决定，不由译者、出版社、年份或 ISBN 是否齐全决定。**

# 六、与原计划相比的主要修改

1. **中译本从“完整书目门槛”调整为“中文展示名优先”。**
   页面优先使用通行中译名；版本细节缺失不阻断文学空间扩充。
2. **路易斯·塞普尔维达明显提前。**
   中文出版数量多，普通中文读者可立即形成阅读路径。
3. **瓜达卢佩·内特尔进入正式规划。**
   2025 年已有三种简体中文作品同步形成系列。
4. **当代作家不再仅按国际声誉或中译本数量硬排。**
   路易塞利、巴斯克斯、梅尔乔等按文学质量与空间覆盖价值动态进入；无需先核验 3 部中文作品的完整版本信息。
5. **诗人允许“中文合集型可读”。**
   米斯特拉尔、帕拉、皮扎尼克、达里奥等不能机械要求三个独立中文单行本；如果正式中文合集完整覆盖代表创作，则可以进入。
6. **中文展示名与 Research Evidence 完全分离。**
   中文名称服务读者识别；“文学判断成立”仍由 Research Data 的正式来源体系证明。译者、出版社、年份与 ISBN 不替代文学证据，也不构成本阶段准入门槛。
7. **先展示文学空间，再逐步补书目深度。**
   全量译本整理属于后续书目增强任务，不嵌入每个小 Batch 的关键路径。

版本号应由**实际内容规模和产品变化**决定，而不是机械按批次数递增。

# 八、每个批次的验收指标

每批至少检查：

### Research

- 3 位新作家均通过实体查重；
- 新作家 9 部计划作品不存在重复实体；
- 作品作者关系有直接来源；
- 重要事实有来源；
- 解释型关系仍按既有证据标准；
- 不为凑数量降低 `hold / gap / disputed` 标准。

### 中文可读性

- T1/T2/T3 只作批次排序参考，不作为 Research 准入门槛；
- 计划进入网站主阅读入口的作品优先使用已出版或通行中文名称；
- 原文题名必须保留，中文展示名及其状态单独登记；
- 译者、出版社、年份和 ISBN 可选，不以缺失判定 FAIL/HOLD；
- 旧译名与新译名建立 alias，不制造重复作品。

### Geo

- 只为已有研究依据的地点建立关系；
- 虚构地点不设置现实经纬度；
- 地图新增节点必须能连接作家或作品。

### Curation

- 每位新增作家至少具备：
  - 一句 reader lede；
  - 为什么值得认识；
  - 3 个代表作入口；
  - 基础阅读顺序；
- 价值判断与 Research Fact 分离。

### Web

- 新作者页正常生成；
- 新作品页正常生成；
- 搜索可找到中文名、原文名和主要译名；
- 地图关系正确；
- 国家 Context Panel 可发现新增作家/作品；
- 无前端硬编码研究事实；
- 浏览器 smoke 通过。

# 九、最终原则

这套计划不追求“把拉美名作家名单塞满数据库”，而是要建立：

> **中文读者可以真正进入的、来源可靠的拉丁美洲文学网络。**

因此扩充优先级应长期遵循：

```text
文学史重要性
→ 国别/时代/性别/体裁代表性
→ 地图与文学关系价值
→ 资料可靠性
→ 中文展示与阅读入口便利度
```

如果一位作家极其重要但暂时缺乏足够中译本：

- 仍可进入 Research Data 和文学空间；
- 有通行中文名时直接用于展示，没有稳定译名时使用明确标记的暂定展示名；
- 后续出现成熟译本时再补 alias 和书目字段，不回头阻塞当前批次。

反过来，如果一位当代作家中文译介成熟、作品质量高、能够显著增强中文读者体验，则可以适当提前。

## 十、本轮检索依据（规划用途）

本计划的中文展示名与可读性判断可参考：

- 豆瓣图书的具体中文版本、作者作品列表和丛书信息；
- “新拉丁美洲文学丛书”（作家出版社，2024 年起）；
- 上海译文、人民文学、译林、作家出版社、外研社等正式出版信息；
- 诺贝尔奖官网关于米斯特拉尔、阿斯图里亚斯、帕斯等作家的资料；
- 中国作家网关于“拉丁美洲文学翻译与中国当代文学”的研究梳理。

这些检索只用于**规划、知名度辅助判断和中文展示名确认**，不要求为每部作品完整采集版本元数据。
正式 Research Data 仍按本项目既有来源等级、Reviewer 与 SQLite migration 规则执行。
