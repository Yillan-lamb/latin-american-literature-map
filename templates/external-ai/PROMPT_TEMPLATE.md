# 外部 AI 短启动提示词

请先替换所有 `<...>` 内容，再把本提示词、任务目录模板、项目规范和输入资料一起交给外部 AI。

```text
请执行“拉丁美洲文学地图”任务 `<TASK-ID>`。

任务卡：<README 绝对或工作区相对路径>
输入：<输入路径>
交付：<交付目录>

请先完整读取任务卡及其中引用的章程和规范，严格按 `package_profile` 交付。所有事实至少关联来源 ID 和来源题名；书籍到书名、论文到论文名、网页到页面标题和 URL 即可，不要求逐页录入。

完成前运行机械检查。完成后只回复：最终状态、交付目录、机械检查结果、HANDOFF 三行摘要。
```
